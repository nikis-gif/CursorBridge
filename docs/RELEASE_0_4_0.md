# Cursor Bridge v0.4.0 - Place projects and editor polish / Projetos por Place e melhorias no editor

## PT-BR

- Espaços locais e persistentes por Roblox Place: histórico de conversas, anotações de arquitetura e códigos Luau salvos, sem depender de serviços externos.
- Nova ação **Save active script** para arquivar o script aberto na biblioteca local, sem modificar o Roblox Studio.
- Editor dividido organizado: scripts fixados no painel secundário não aparecem duplicados nas abas do painel principal quando são documentos diferentes.
- Interface e atalhos aprimorados, preservando Ctrl+Z, Ctrl+Y, busca, substituição e demais comandos do Monaco.
- Correções de segurança: isolamento do contexto do script por Place, proteção de credenciais e cancelamento de requisições.
- Regressão automatizada de navegação, Quick Apply, Places grandes, editor Monaco e empacotamento Windows.

**Importante:** a versão pública **não habilita login com ChatGPT nem geração de respostas por modelos de IA**. O repositório permanece `UNLICENSED`; elegibilidade de distribuição e testes nativos de login ainda dependem de aprovação. As funções locais de projetos e códigos continuam disponíveis sem API. O histórico de conversas locais não corresponde ao do ChatGPT.com.

O pacote de ícones Vanilla 3 enviado pelo usuário não foi incluído devido às restrições de licença.

## English

- Local Place-specific records with independent conversations, manual project notes and saved Luau snippets.
- **Save active script** archives the opened Studio script locally without editing Studio.
- Clear primary/secondary editor tabs; Monaco undo/redo and developer shortcuts preserved.
- Windows packaging, plugin integrity, actual Monaco UI, Quick Apply, and large-Place automated regression verified.

**Important:** the public v0.4.0 installer **does not enable Sign in with ChatGPT or model inference**. OSS deployment eligibility and native login QA remain pending. The repository retains its `UNLICENSED` status; no redistribution license has been added.

No proprietary Vanilla 3 assets were included.
